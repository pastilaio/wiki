Интерфейс

Главное окно разделено на зоны: дерево, панель файлов, детали и верхний тулбар.

Заголовок окна

Слева — логотип и название. Справа — кнопки свернуть, развернуть, закрыть. Под заголовком — верхний тулбар:

  • Домой — стартовая страница;
  • Файлы — вернуться к панели с карточками;
  • Поиск — фильтр дерева (Ctrl+F);
  • Сортировка — A→Z / Z→A в дереве;
  • Избранное / Напечатано — фильтры дерева;
  • Свернуть всё — свернуть ветки дерева;
  • Загрузка — добавить файл в корень;
  • + — меню: файл, папка, панель.

Левая панель (дерево)

Иерархия папок, панелей и системных разделов. Клик по папке или панели открывает её содержимое в центре. Узлы можно перетаскивать, выделять несколько (Ctrl+клик), вызывать контекстное меню правой кнопкой.

Внизу узкой полосой — быстрые кнопки: материалы, настройки, помощь, переключение светлой/тёмной темы.

Центральная панель (файлы)

Отображает содержимое выбранной панели в виде карточек или компактного списка. Вверху — вкладки: средняя кнопка мыши по папке в дереве открывает новую вкладку; средняя кнопка по вкладке закрывает её (кроме закреплённых). Закрепить вкладку — ПКМ → «Закрепить вкладку». Путь «Хранилище / Папка / Подпапка»: клик по «Хранилище» открывает список папок верхнего уровня; клик по сегменту — переход; ПКМ — открыть, новая вкладка, копировать путь, показать в проводнике, закладка. Файлы можно перетащить на вкладку или из дерева на вкладку. Закладки папок — кнопка в верхнем тулбаре и блок на стартовой странице; добавить: ПКМ по папке в дереве или вкладке.

В правом углу строки пути — две кнопки: переключение сетка / компактный список и воронка, которая скрывает и показывает панель фильтров над файлами. Состояние воронки запоминается и восстанавливается при следующем запуске программы.

Правая панель (детали)

При выборе файла показывает:

  • превью 3D (для STL) или изображение;
  • имя, размер, путь;
  • материал и цвет печати;
  • теги;
  • кнопки открыть, избранное, напечатано.

Панель можно свернуть кнопкой на её краю. Ширину меняют перетаскиванием разделителя.
