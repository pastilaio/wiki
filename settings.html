Настройки и резервные копии

Параметры приложения, темы, backup и обновления.

Установка и папки

  • Программа — каталог, выбранный в установщике (по умолчанию %AppData%\Pastila).
  • Настройки приложения — %AppData%\Pastila\data\settings.json (язык, тема, путь к хранилищу).
  • Хранилище — отдельная папка с моделями; задаётся в установщике или в настройках.

Хранилище

  • Папка проекта — где лежат все данные.
  • Статистика — размер, число файлов, превью.
  • Количество файлов в папках и панелях — в дереве слева справа от имени показывается число файлов (включая вложенные).
  • Следить за папкой (Debug) — синхронизация с диском.

Язык и тема

  • Русский / English.
  • Выбор темы оформления и стиля (светлый / тёмный / цветовые схемы).
  • Кнопка солнца/луны в боковой панели быстро переключает светлый и тёмный режим.

Обслуживание

Раздел Обслуживание в настройках:

  • Очистка хранилища — сканирование лишних превью, записей без файла, пустых папок и крупных файлов; можно применить безопасные исправления одной кнопкой.
  • Автоочистка корзины — число дней (0 = выкл.); при запуске элементы старше N дней удаляются навсегда.
  • Плановый backup — интервал, папка назначения; напоминание или автоматическое создание ZIP.

Резервное копирование

System → Create backup — ZIP всего хранилища (structure, materials, files, previews) в выбранную папку.

Restore storage — восстановление из архива (осторожно: перезапишет текущие данные).

Обновления

В блоке System:

  • Экспорт / импорт настроек — сохранить или загрузить JSON с настройками интерфейса (без папки хранилища).
  • Проверить обновления — ручная проверка; при наличии версии появится кнопка «Обновить».
  • Автопроверка и автоустановка — по расписанию при указанном URL сервера.
  • При загрузке показывается прогресс; пакет проверяется по SHA-256, если хеш указан в manifest.json.
  • На стартовой странице отображается блок «Обновление», если найдена новая версия.

Сообщить о проблеме

На встроенной странице Помощь есть форма обратной связи. Сообщение отправляется на сервер обновлений (если настроен) или сохраняется локально в папку feedback профиля приложения — с кнопкой «Открыть папку с отчётом».

Debug

  • Журнал синхронизации с диском.
  • Очистка структуры дерева (без удаления файлов с диска — только сброс structure.json).
  • Порог вкладок до появления прокрутки.
Настройки интерфейса (ширина панелей, открытые вкладки, позиция прокрутки на странице настроек) сохраняются автоматически в settings.json рядом с приложением.
