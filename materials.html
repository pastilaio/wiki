Материалы

Справочник филаментов: тип, производитель, цвет — и привязка к каждой модели.

Страница «Материалы»

Откройте кнопкой в нижней панели дерева. Четыре таблицы:

  1. Производители — бренды (Prusament, eSUN…).
  2. Типы — PLA, PETG, ABS…
  3. Цвета — название и образец цвета.
  4. Материалы — конкретная связка: имя + тип + производитель.

Ячейки таблиц редактируются кликом. Есть поиск по всем спискам.

Привязка к файлу

Выберите файл — в правой панели «Детали файла»:

  • выпадающий список Материал;
  • выпадающий список Цвет печати с цветным индикатором.

На карточке файла в панели отображается бейдж с материалом.

Фильтр в панели

Над карточками можно отфильтровать файлы по материалу или цвету — удобно, когда ищете «всё чёрное PETG».

Удаление материала

При удалении записи из справочника программа предупредит, сколько файлов на неё ссылаются. Можно снять привязку со всех файлов перед удалением.

Данные хранятся в materials.json внутри папки проекта и попадают в резервную копию вместе с остальным хранилищем.
