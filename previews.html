Превью моделей

Миниатюры на карточках файлов и в правой панели.

Автоматическое создание

При загрузке или переименовании файла Pastila пытается создать PNG-превью для:

  • изображений (JPG, PNG…);
  • моделей STL, OBJ, 3MF.

Файлы превью хранятся в папке previews/ внутри хранилища.

3D-превью в правой панели

Для STL, OBJ и 3MF отображается интерактивный просмотр:

  • Вращение — перетаскивание левой кнопкой мыши по модели;
  • Масштаб — колёсико мыши или кнопки ± на панели;
  • Полный вид / каркас — кнопка с кубом после кнопки сетки переключает способ отображения модели;
  • Куб ориентации — небольшой каркасный куб с цветными осями X, Y и Z в левом нижнем углу. Перетаскивайте его для свободного вращения камеры; короткий клик по невидимой грани включает стандартный вид.

Кнопка Pin фиксирует ракурс — тогда автоматическая перегенерация превью для этого файла не выполняется.

Пакетное создание

Если у части файлов нет миниатюр (старый импорт, сбой):

  1. Откройте Настройки → Разное.
  2. Нажмите Создать отсутствующие превью.
  3. Дождитесь окончания — отображается прогресс.

Обрабатываются только файлы без превью или с отсутствующим PNG на диске. Файлы с закреплённым (Pin) видом пропускаются.

Размер карточек

Размер превью на карточках настраивается в настройках (параметр размера превью / шрифта имён файлов).
