Теги

Произвольные метки на файлах для поиска и группировки.

Добавление тегов

Выберите файл → правая панель → блок Теги:

  • введите тег и нажмите Enter;
  • клик по чипу с крестиком удаляет тег с файла;
  • при вводе подсказываются уже существующие теги (выпадающий список под полем).

Автотеги при загрузке

При добавлении файла с расширением stl, obj, 3mf или zip Pastila автоматически ставит тег с именем расширения — удобно для фильтрации в панели. Тег можно удалить или дополнить вручную.

Массовое добавление

Выделите несколько файлов в дереве или панели → контекстное меню → Добавить тег…. Можно ввести несколько тегов через запятую.

Поиск и фильтры

  • Поиск в дереве (Ctrl+F) учитывает теги.
  • Глобальный поиск (Ctrl+Shift+F) тоже.
  • В панели файлов — фильтр по тегу и пункт Без тегов.

Теги отображаются чипами на карточках файлов.

Менеджер тегов

Настройки → Разное → Управление тегами

Таблица всех тегов с количеством файлов. Для каждого тега:

ДействиеЧто делает
ПереименоватьМеняет имя тега на всех файлах
ОбъединитьЗаменяет этот тег на другой: файлы с тегом A получают тег B, A исчезает
УдалитьСнимает тег со всех файлов

Пример объединения

Есть теги запчасть и деталь. Объединяем «запчасть» → «деталь»: у всех файлов с «запчасть» этот тег убирается, добавляется «деталь» (если его ещё не было).
